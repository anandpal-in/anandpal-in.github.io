# Dr. Anand Pal
**Live at:** https://anandpal.in

Every type of content lives in one file. Edit that file and every page that shows it updates automatically.

| To add or change… | Edit | Appears on |
|---|---|---|
| An article | a new file in `_writing/` (see below) | Writing, homepage, related articles, RSS feed, sitemap |
| A publication | top of `_data/publications.yml` | Publications (by year, filters), Research (per area) |
| A talk or podcast | top of `_data/talks.yml` | Talks, homepage |
| A student | `_data/group.yml` | Research → Research Group |
| A course | `_data/courses.yml` | Teaching |
| Research areas | `_data/research_areas.yml` | Research, Publications filters |
| Citation figures, email, profile links | `_data/profile.yml` | Publications, Contact, footer |
| Menu items and order | `_data/navigation.yml` | Top menu |

Each data file explains its fields in a comment at the top.

## Publishing an article

1. Copy `_writing/_TEMPLATE.md` to a new file in `_writing/`, e.g. `_writing/science-and-trust.md`.
   The file name becomes the address: `https://anandpal.in/writing/science-and-trust/`.
2. Fill in `title`, `subtitle`, `date`, `category` and `summary`, and write the article below the front matter (Markdown or HTML).
3. Optional lead image: put it in `assets/images/writing/` and add `image:`, `image_alt:` and `image_credit:`.
4. Delete the `published: false` line when it is ready.

The article page, reading time, share buttons, link previews and related articles are generated by
`_layouts/article.html`.

- **Drafts:** keep `published: false`. To preview drafts locally: `jekyll serve --unpublished`.
- **Categories:** any text works; use the same spelling each time so articles group together.
- **Author bio** shown under every article: `_includes/author-bio.html`.

## Moving or renaming a page

Add a file to `_redirects/` so the old address keeps working, e.g. `_redirects/old-name.html`:

```
---
layout: redirect
permalink: /old/address/
redirect_to: /new/address/
---
```

## Testing locally

```
jekyll serve        # then open http://127.0.0.1:4000
```

## Site-wide spacing

Section spacing is controlled by three variables in the "SPACING SYSTEM" block at the end of
`assets/css/styles.css` (`--section-y`, `--heading-gap`, `--block-gap`).

## Folder structure
```
├── _config.yml              ← site settings, collections
├── _writing/                ← ARTICLES: one file per article (+ _TEMPLATE.md)
├── _data/                   ← publications, talks, group, courses, profile, navigation, research areas, books
├── _layouts/
│   ├── default.html         ← page shell: head, link previews, nav, footer
│   ├── article.html         ← article page template
│   └── redirect.html        ← used by _redirects/
├── _includes/               ← nav, footer, icons, author bio, publication entry, reading time
├── _redirects/              ← old addresses that forward to new ones
├── assets/                  ← css, js, images (article images in assets/images/writing/)
├── index.html               ← homepage
├── about/ research/ publications/ teaching/ writing/ talks/ contact/
├── feed.xml, sitemap.xml    ← generated automatically
└── 404.html
```

Not published: `CV_Anand-Pal.pdf` and `rough/` (excluded in `_config.yml` and `.gitignore`).
