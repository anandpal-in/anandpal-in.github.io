# Dr. Anand Pal

**Website:** [anandpal.in](https://anandpal.in)

Personal website of Dr. Anand Pal, physicist, educator, and public thinker, writing about science,
technology, education, and their place in society.

The site brings together:

- **Writing**: essays and commentary on science policy, higher education, and the ideas shaping society
- **Research**: work in experimental condensed-matter physics, including superconductivity, quantum magnetism, and materials for energy
- **Publications**: journal articles and conference papers
- **Teaching**: courses and teaching philosophy
- **Talks**: invited talks, public lectures, and conversations

## About this repository

The website is built with [Jekyll](https://jekyllrb.com/) and hosted on GitHub Pages.
